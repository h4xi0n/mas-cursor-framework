# Brainstorm Brief — MAS-01

## Problem & User Outcome

**Problem:** MAS already isolates subagent context and uses brief-on-disk handoffs, but token cost scales poorly without tiered model routing, artifact-forwarding semantics, explicit loop caps, or install-path deduplication. Repeated Reviewer rejections risk degeneration-of-thought without bounded multi-perspective review.

**User outcome:** Run `/mas` and `/mas-lite` workflows with measurably lower token spend, clearer handoff contracts, no duplicate install maintenance, and optional capped group discussion only when quality gates fail — without abandoning deterministic Coordinator routing.

**UI scope:** `logic-only` — protocol, skills, scripts, handoff fields, artifact schemas only. No UI files or presentation-layer work.

**OSINT delta:** Industry consensus (LangGraph forward, MetaGPT artifact bus, Anthropic tiered workers, MAD/MAR capped debate) aligns with MAS strengths. This brief operationalizes OSINT priorities #1, #4, #7, #8 plus install dedup.

## Logic Flow

### A. Normal specialist chain (unchanged topology)

1. Coordinator assigns `TASK_ID`, runs `init-workflow-session.ps1`.
2. Coordinator writes handoff with `MODEL_CLASS`, `BRIEF_PATH` refs (not inline bodies), `SPAWN_STATUS: spawned`.
3. Coordinator spawns Task with `model` param mapped from `MODEL_CLASS` per `spawn-model-policy.md`.
4. Specialist reads handoff → skill → `read-order.md` files → optional `BRIEF_PATH` + `SECTIONS:` slices only.
5. Specialist writes deliverable brief; validates against `brief-schemas.md` required sections.
6. Coordinator records step via `record-workflow-step.ps1`; user summary = **one line + path** (artifact-forward, no paraphrase of full brief).
7. Coordinator sets `SPAWN_STATUS: complete`; routes via routing table (deterministic, zero-token).

### B. Reviewer rejection with caps

1. Reviewer returns `Approved: NO` → increment `reviewer_loop_count` in session JSON.
2. If `reviewer_loop_count == 1` → standard bug-fix handoff with filtered findings (`agents-as-tools` pattern: findings only, not full chain).
3. If `reviewer_loop_count == 2` and `debate_used == false` → spawn **debate micro-chain** (max 1 session per `TASK_ID`):
   - Round 1: security-persona critic + simplicity-persona critic (both `fast`, read reviewer brief + changed files list).
   - Synthesizer (`mas-debate`, `normal`) writes `.ai/context/debates/{TASK_ID}.md` with consensus + dissent.
   - Max 2 rounds; break early if critics agree.
4. Bug-fix reads `debates/{TASK_ID}.md` + reviewer findings → dev retry.
5. If `reviewer_loop_count >= MAX_REVIEWER_LOOPS` (2) after debate → Coordinator escalates to user (no further auto-spawn).

### C. Post-workflow token audit (optional, qualified workflows only)

1. After `finalize-workflow-usage.ps1` on `Approved: YES` + non-empty `FILES`.
2. Coordinator may spawn `mas-token-auditor` (`fast`, foreground) with session JSON path.
3. Auditor writes `.ai/context/audits/{TASK_ID}.md`: per-step token breakdown, outliers, suggestions (e.g. "OSINT used thinking — downgrade to fast").
4. Auditor does **not** block workflow; advisory only. Omit in Lite unless user requests.

### D. Install deduplication

1. **Canonical source:** `skills/multi-agent-system/install/` (co-located with protocol/skills).
2. **Root `install/`:** Remove from repo OR replace with `README.md` pointer + re-export in `export-mas-framework.ps1` only.
3. **Install scripts:** Resolve framework root relative to `$PSScriptRoot` (already pattern); update `manifest.json` paths if needed.
4. **CI guard (future):** Hash check in export script fails if root copy reappears.

## Domain & Contracts

### Protocol constants (`token-rules.md` additions)

| Constant | Full `/mas` | Lite |
|----------|-------------|------|
| `MAX_CHAIN_AGENTS` | 12 | S=2, M=2, L=3, L+=4 |
| `MAX_REVIEWER_LOOPS` | 2 | 2 |
| `MAX_DEBATE_ROUNDS` | 2 | 1 (lite: single round) |
| `MAX_DEBATE_SESSIONS_PER_TASK` | 1 | 1 |

### Handoff fields (extensions)

```
MODEL_CLASS: fast | normal | thinking
BRIEF_PATH: .ai/context/brainstorms/MAS-01.md
SECTIONS: Recommended, Edge Cases   # optional slice; omit = read full brief
DEBATE_TRIGGER: reviewer-rejection-2  # Coordinator-only
```

Lite abbreviation: `MC: fast` on line with `MODE: LITE` (Planner must document in handoff-format-lite.md).

### Spawn model policy (default map)

| Agent slug | `MODEL_CLASS` | Task `model` hint |
|------------|---------------|-------------------|
| osint, imaginer, documenter, spec-reader, token-auditor | fast | `composer-2.5-fast` |
| planner, brainstorm, test-strategy, ux-intelligence, android-dev, general-dev, bug-fix | normal | default / `composer-2.5` |
| architect, reviewer (full), debate-synthesizer | thinking | `claude-opus-*-thinking-high` |
| coordinator | normal | (inline routing only) |

Override via handoff `MODEL_CLASS:`; Coordinator passes to Task `model` when supported.

| Agent | Startup reads (beyond read-order base) |
|-------|----------------------------------------|
| brainstorm | `osint/{TASK_ID}.md`, `specs/{TASK_ID}.md` if exists |

### New agent: `mas-debate` (debate-synthesizer)

- **Trigger:** Coordinator only; `reviewer_loop_count >= 2`.
- **Personas:** security-critic, simplicity-critic (prompt templates in skill; not separate spawns in v1 — single synthesizer runs both personas sequentially to cap spawn count).
- **Output:** `.ai/context/debates/{TASK_ID}.md`
- **NEXT_AGENT:** bug-fix
- **Not for:** feature brainstorming (use `mas-brainstorm`).

### New agent: `mas-token-auditor`

- **Trigger:** Post-finalize, optional, user opt-in or Coordinator heuristic (e.g. `tokens=unknown` on 3+ steps).
- **Input:** session JSON + memory workflow bullet.
- **Output:** `.ai/context/audits/{TASK_ID}.md`
- **Never:** blocks approval or modifies memory.

### Session JSON extension

```json
{
  "reviewer_loop_count": 0,
  "debate_used": false,
  "debate_round": 0
}
```

## Edge Cases

| Case | Behavior |
|------|----------|
| `MODEL_CLASS` omitted on handoff | Derive from spawn-model-policy default table |
| Task `model` param unsupported / rejected | Fall back to default; record `model: default` in session |
| Brief missing required schema sections | Specialist still completes; Reviewer flags incomplete brief as `Approved: NO` with schema gap |
| `SECTIONS:` references nonexistent headers | Read full brief; log warning in Coordinator summary |
| Debate after 1st rejection only | Skip — debate triggers only on 2nd `Approved: NO` |
| User cancels mid-debate | `cancel-workflow-session.ps1`; `debate_used` preserved if partial brief exists |
| Lite 12-line handoff overflow | Abbreviate: `MC:fast`, `BP:.ai/context/...`; document in lite format |
| Parallel OSINT + Spec Reader (deferred) | Not in v1; require explicit user flag `PARALLEL_READ: YES` in future protocol revision |
| Root vs nested install drift | Export script hashes nested canonical; fail build if root copy differs |
| Token auditor on planning-only chain | Skip — no finalize qualification |

## Quality Bar

- **Idempotency:** Re-spawn same agent after Reviewer `NO` replaces session step (existing workflow-usage behavior); debate session idempotent per TASK_ID.
- **Observability:** Every spawn records `model`, `model_class`, `tokens_*` in session JSON; auditor summarizes outliers.
- **Security:** Debate critics must not paste secrets from codebase; handoff FILES scope only.
- **Fail-safe:** Cap breach → user escalation message with paths to reviewer + debate briefs.
- **Regression:** Existing chains without new fields behave unchanged (defaults apply).
- **Tests (logic layer):**
  - Unit: schema validator script (optional v1) checks brief headings.
  - Integration: dry-run handoff parse for `BRIEF_PATH` + `SECTIONS`.
  - Manual: run MAS-01 chain; verify Coordinator chat does not inline brief bodies.
